# KinGuide demo script (2–3 minutes)

Use **Explore sample family** only.

1. **0:00–0:20 — Opening**  
   “KinGuide helps organise family medical history and prepare a clinician conversation. It is an educational prototype, not a medical device.”

2. **0:20–0:50 — Dashboard**  
   Show live counts (members, history, missing items). Click **Run assessment**.

3. **0:50–1:20 — Family tree**  
   Open Family Tree. Point out generations by colour. Zoom/pan.

4. **1:20–1:50 — Missing info + Findings**  
   Show Missing Info (unknown ages stay unknown). Open Findings: MEETS / DISCUSS with step-by-step YES/NO/UNKNOWN.

5. **1:50–2:20 — Report**  
   Open Reports → copy/print sheet. Emphasise disclaimer.

6. **2:20–2:45 — Privacy + ask**  
   “Data stays in the browser. I’m seeking mentorship and feedback—not a purchase yet.”

7. **2:45–3:00 — Close**  
   “What would you need to see for a responsible next step?”
