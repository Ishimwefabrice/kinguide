# KinGuide outreach pack (AUCA → partners)

Use this folder when contacting NHIC, timbuktoo, Norrsken, kLab, etc.

## Status (honest)

KinGuide is a **working educational prototype**: family tree, medical history, missing info, demonstration rule engine, findings, reports, local IndexedDB storage.

It is **not** a medical device and is **not** clinically validated.

## Send order (recommended)

1. AUCA supervisor review  
2. NHIC (`nhic@moh.gov.rw`) — feedback only  
3. timbuktoo HealthTech Hub — mentorship / LaunchPad interest  
4. Norrsken / kLab — networking  
5. Later: eFiche, HISP Rwanda, RBC — expert review  

First ask = **20-minute feedback meeting**, not money.
